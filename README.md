# Bestie Foreverrr ♡

A cute 9-page friendship website with Hinglish text, pastel colour changes, sparkles, a promise checklist, a letter reveal, a wish candle, 100 reasons, and a photo gallery.

## Files
- `index.html` — Page 1 welcome
- `promises.html` — Page 2: 10 promises; all 10 need to be checked to continue
- `oops.html` — playful warning if Next is clicked too early
- `memory.html` — Page 3: one photo and a little note
- `letter.html` — Page 4: click the scroll to open the Hinglish letter
- `surprise.html` — Page 5: bestie certificate
- `little-things.html` — Page 6: reminders
- `birthday.html` — Page 7: click the candle flame and write a wish
- `100-things.html` — Page 8: 100 things I like about you
- `photos.html` — Page 9: remaining photos
- `style.css` — styling and animations
- `script.js` — interactions
- All 9 photos (`memory-1.jpeg` to `memory-9.jpeg`) are in the same folder as the website files.

## Run it
Open `index.html` in a browser, or upload all files and the `pics` folder to the root of your GitHub repository. Enable GitHub Pages in the repository settings to publish it.

Keep the `pics` folder name unchanged so all photos load correctly.
